# Pedidos · Distribuciones El Progreso

Prototipo del Reto ADSO "Operación Empresa Digital". Registra y consulta pedidos (cliente, producto, cantidad, estado) con React + TypeScript + Vite.

## Ejecutar
```bash
npm install
npm run dev
```
Abre la dirección que muestra la terminal (normalmente http://localhost:5173).

## Estructura
- `src/types.ts`: tipos `Pedido` y `EstadoPedido`
- `src/App.tsx`: estado de los pedidos (en memoria) y resumen
- `src/components/OrderForm.tsx`: formulario con validaciones
- `src/components/OrderList.tsx`: tabla con estados
- `docs/ANALISIS.md`: problema, requerimientos y boceto
